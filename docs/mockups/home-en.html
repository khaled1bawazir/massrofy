S-08 — Home (English / LTR mirror)

This is not a separate screen — it is the exact same Home screen as home.html, rendered under the English/LTR locale to demonstrate the RTL↔LTR mirroring rule (brand.md §3.3): the layout, list leading/trailing order, chevrons and the budget-progress fill direction all flip, while numerals and currency codes stay left-to-right internally in both locales. Every other screen in this set is designed the same way; only Home is duplicated here as the reference example. Latin UI text here renders in Manrope; the Arabic mirror (home.html) renders in Tajawal, per brand.md v1.1 §3.
